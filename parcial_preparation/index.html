  1. Corrida en frío:

    2. Es analizar el código para poder predecir su comportamiento previo a su ejecución.

  2. Qué es el frontend:

    3. Es la parte con la que el usuario puede interactuar en un sitio web, el cual usualmente está compuesto por: HTML, CSS y Javascript, el cual además puede ser visto como las partes del cuerpo humano como por ejemplo

    • HTML:

      • Este sería la parte del esqueleto, me recuerda mucho a trabajar en word pero con más pasos.

    • CSS:

      • Esta sería la parte de la piel y toda su decoración cómo sería incluso el pelo y su color, es lo que hace que un sitio se vea mucho más bonito en realidad.

    • JavaScript:

      • Este sería el cerebro encargado de procesar las partes lógicas de todo el cuerpo y los distintos sistemas que tiene.

  3. Qué es el backend:

    4. Es la parte trasera de los sitios web con la que el usuario no puede interactuar en si allí se manejan API's, bases de datos, servidores, domains, y cosas que dan miedo.

  4. Estructura organizacional de un proyecto web:

    5. Es posible que en un mismo archivo HTML se pueda trabajar con CSS y Javascript pero a la hora de tener proyectos más grandes resultará muy díficil llevar un control en ellos por ello es necesario dividir el proyecto en tres partes que traten individualmente con cada lenguaje:

    • CSS (Carpeta)
    • HTML (Archivos HTML)
    • JS (Carpeta)
    • index.html (Archivo principal)

  5. HTML: Elementos y atributos y etiquetas.

    6. Elementos: Están definidos por

    • Etiqueta de apertura: indica por donde comienza un elemento
    • Contenido de la etiqueta
    • Etiqueta de Cierre: indica donde termina un elemento

  6. CSS: sintaxis, selectores y propiedades.

    • Sintaxis: Es una regla de CSS consiste en uno o varios selectores seguido de un bloque de declaración.
    • Selectores: Nos permiten seleccionar un elemento específico de nuestro archivo HTML o también seleccionar todo lo del archivo
    • Propiedades: Nos permiten cambiar ciertos valores y ajustar elementos del archivo, sea el tamaño, color, posición y todo lo de un elemento o varios de HTML
